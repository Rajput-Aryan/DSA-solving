## 📝 Problem Statement

Given an integer array **arr[]** , return the **sum** of all elements of arr.

### ⚡ Examples

**Input:** arr[] = [1, 2, 3, 4]

**Output:** 10

**Explanation:** 1 + 2 + 3 + 4 = 10.

**Input:** arr[] = [1, 3, 3]

**Output:** 7

**Explanation:** 1 + 3 + 3 = 7.

### 🔒 Constraints

1 <= arr.size <= 10^5

1 <= arr[i] <= 10^4
