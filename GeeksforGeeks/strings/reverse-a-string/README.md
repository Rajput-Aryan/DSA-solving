## 📝 Problem Statement

You are given a string **`s`** , and your task is to reverse the string.

### ⚡ Examples

**Input:** s = "Geeks"

**Output:** "skeeG"

**Input:** s = "for"

**Output:** "rof"

**Input:** s = "a"

**Output:** "a"

### 🔒 Constraints

1 <= s.size() <= 10^6s contains only alphabetic characters (both uppercase and lowercase).
